# Novel2Anime Studio 桌面应用

## 1. 启动

在项目根目录双击 `start_gui.bat`，或在 PowerShell 执行：

```powershell
cd E:\yjd\video\video
.\.venv\Scripts\python.exe main.py gui
```

应用只在本机运行，不需要启动浏览器。

## 2. 页面

- **项目总览**：优先显示当前最应该完成的下一步；所有统计卡片、生产流程步骤和服务器模块均可点击跳转。
- **小说导入**：选择 TXT、Markdown 或章节 JSON，自动切章、分析人物并生成分镜；三个结果页签可随时查看处理结果。
- **角色定妆**：编辑角色提示词、选择预设风格，按照“选择角色 → 生成候选 → 选定定妆照”的顺序完成选角。
- **声音角色库**：导入授权音色、试听声音，自动分析人物特征并完成声音选角，也可逐人手动调整。
- **本地资源包**：一键整理并直接打开人物、场景、人声和按集分类的合成内容。
- **分镜脚本**：切换剧集和镜头，修改英文生图提示词并保存镜头风格。
- **视频生成**：生成 Wan 人物动作视频、无声预览、逐镜头配音、字幕和带声成片。
- **任务与日志**：查看 SQLite 中的任务状态，以及当前桌面应用会话的连接和生成日志。
- **连接设置**：配置 GPU 服务器 SSH 地址、端口、用户名和密码，检测服务器或启动 ComfyUI。

## 3. 管理多个项目

点击顶部的“新建项目”，填写项目名称与项目标识即可创建独立项目。顶部项目下拉框用于切换项目。

每个项目独立保存：

- 小说、章节数据库与分析结果
- Episode 和分镜
- 角色候选图与已选定的定妆照
- 视频、音频和日志

切换项目后，所有页面会自动刷新为该项目的数据。

### 本地资源包

进入左侧“本地资源包”，点击“整理并刷新资源包”。应用不会删除生产源文件，而是
优先使用硬链接建立清晰、可直接交付的资源视图。四个卡片都可以一键在 Windows
资源管理器打开：

```text
projects/<项目名>/assets/characters/          # 人物定妆与人物清单
projects/<项目名>/assets/locations/           # 场景参考图与场景清单
projects/<项目名>/assets/voices/              # 人声试听、授权与声音清单
projects/<项目名>/outputs/episodes/           # 按集整理的合成内容
```

每集成片包的结构如下：

```text
outputs/episodes/<项目拼音_集号>/
├── shipin/                 # 最终 MP4
├── zimu/                   # 整集 SRT
│   └── fenduan/            # 逐镜头 SRT
├── yinpin/                 # 逐镜头配音
├── qingdan/                # 整集生成清单
│   └── fenduan/            # 逐镜头生成清单
├── zhijian/                # 质检抽帧
└── shuoming.txt
```

文件名只使用拼音、数字和下划线，例如：

```text
jueshi_001_001_20260804_204013_chengpian.mp4
jueshi_001_001_20260804_204013_zimu.srt
qin_feng_001_005_001_20260804_204013.mp3
```

## 4. 第一次生成并选定角色

1. 打开“连接设置”。
2. 确认服务器地址、SSH 端口和用户名。
3. 输入 SSH 密码。密码只保存在当前应用进程内，关闭应用后清除。
4. 点击“检测连接”。状态应显示服务器、ComfyUI 与可用模型均已就绪。
5. 打开“角色定妆”，选择人物。
6. 选择一个或多个生图模型，并选择普通定妆照或三视图构图预设。
7. 设置每个模型的候选数量和随机种子。
8. 点击“使用所选模型生成”。
9. 比较候选图，点击满意图片下方的“设为定妆照”。

生成任务在后台线程执行，窗口不会冻结。完成后图片自动下载到：

```text
projects/<项目名>/outputs/server_test/image_app/<人物_时间>/
```

图库会自动刷新。点击“查看大图”可打开单张候选图。选定结果保存在：

```text
projects/<项目名>/production/cast_selection.json
```

生成过程中会显示真实的逐张进度、当前阶段和累计耗时。每张候选图会标注实际模型、生成日期时间（精确到秒）和构图预设。

## 5. 提示词与风格

角色定妆和分镜脚本均支持直接修改提示词。修改后点击对应的“保存提示词”按钮，内容会写回当前 Episode JSON。

内置风格包括：

- 真人电影
- 简笔画
- 油画
- 中国水墨
- 迪士尼动画感
- 游戏 CG

角色生成时，当前风格会自动传给远程工作流。“应用到提示词”按钮可以把风格描述直接追加到可编辑文本中。

角色定妆构图预设包括：

- 普通单人定妆照
- 预设1：白底标准定妆设定板。左侧包含半身与全身的正面、左侧面、
  背面视图；右侧包含 8 格面部正面、侧面、三分之四侧面、背面与表情特写
- 预设2：正面、背面、45°左侧面三视图，有背景

生图模型支持多选。“生成数量”按每个所选模型计算，例如同时选择 2 个模型、数量为 4，会生成 8 张候选图。

### 图片不满意时修改现有图片

角色定妆图库和分镜脚本当前首帧均有“不满意 · 修改此图”按钮：

1. 先选择常见问题，也可以直接填写具体问题与修改要求。
2. 在“修改后的目标提示词”中描述最终画面，而不是只写“更好看”。
3. 在排除项中明确写不要出现的内容，例如 `beard, moustache, extra fingers`。
4. 选择保留程度和 1～4 个候选；局部修脸、手、衣服优先用“严格保留”。
5. 生成完成后比较候选。只有点击“使用这张”才会切换当前图片；点击
   “只保存候选，暂不替换”不会改变当前选择。
6. 分镜页点击“历史版本”可查看模型和生成时间，并恢复任一旧候选。

完整的决策建议、提示词写法、保存目录和故障处理见：
[图片不满意时的修改功能](04-图片不满意时的修改功能.md)。

## 6. 小说导入与自动处理

1. 在顶部选择目标项目。
2. 打开“小说导入”。
3. 选择小说文件。
4. 设置本次自动分析的章节数量；小说本身会完整导入。
5. 点击“导入并自动处理”。
6. 在“切分章节”“提取人物”“生成分镜”三个页签检查结果。

页面会显示整个自动处理流程的进度和耗时。为保证大型小说的界面响应速度，章节表最多预览前 200 章，页签仍会显示实际总章节数。

### 重新处理已有内容

对现有的人物提取或分镜结果不满意时：

1. 在“自动分析”中设置重新处理的章节数量，`0` 表示全部章节。
2. 点击“重新处理已有内容”。
3. 阅读覆盖提示并确认。
4. 应用会跳过小说导入，强制重新分析所选章节并重建对应分镜。

重新处理前，当前 Episode JSON 会自动备份到：

```text
projects/<项目名>/production/backups/reprocess_<年月日_时分秒>/episodes/
```

注意：

- 手工修改过的角色提示词、镜头提示词和分镜风格可能被新结果覆盖。
- 已生成的候选图片和角色定妆选择不会删除。
- 数据库保留历次分析记录用于审计，但总览只按已分析的不同章节数统计。
- 重新处理需要本机 OpenAI-compatible LLM 服务可用。

### 本地文本模型

小说分析使用本机 CPU 运行的 Qwen3.5-9B，不占用远程 3090 生图服务器：

```text
运行时：llama-cpp-python
API：http://localhost:1234/v1
模型：qwen/qwen3.5-9b
文件：models/llm/Qwen.Qwen3.5-9B.Q4_K_M.gguf
上下文：8192 tokens
```

应用启动时会检测本地文本模型。模型文件完整但服务未启动时，应用会自动启动服务；也可以在“连接与设置”中点击“检测文本模型”或“启动本地模型”。

如果服务不可用，小说导入和重新处理会在执行前停止，并显示明确提示，不会再直接显示底层 `HTTPConnectionPool` 异常。运行日志位于：

```text
logs/local_llm.log
```

服务启动时会关闭 Qwen3.5 的思考输出，并对分析结果启用 JSON Schema
约束，避免思考文本挤占输出或造成 JSON 解析失败。

### 连续首帧

“分镜脚本”页会显示每个镜头的连续组、动作节拍、入镜状态、出镜状态、匹配
锚点和参考镜头：

- “自动补全缺失画面”只补尚无首帧的镜头；
- “重做连续首帧”重新生成整集首帧，但保留旧图片作为候选；
- 同场景且出场人物集合一致时，下一镜头使用上一镜头进行适度图生图重绘；
- 人物阵容改变、闪回或换场时自动停止图像引用，避免错误人物和服装逐镜累积；
- 动作首帧默认使用主要动作完成前的预备瞬间，保留身体重心、动作线和运动空间。

每张新图的 Manifest 会保存连续组、参考镜头、参考图和重绘幅度，便于复查。

## 7. 视频生成工作台

分镜确认后打开“视频生成”：

1. 选择剧集。应用会自动识别已保存的镜头首帧和历史镜头视频。
2. 没有首帧的镜头点击“选择/更换首帧”；图片会复制到项目的
   `production/video_inputs/`，避免外部文件移动后失效。
3. 为镜头编辑动作提示词、运镜和时长并保存。
4. 勾选镜头，选择输出分辨率和帧率，点击“生成选中镜头”。
5. 生成后点击“播放当前视频”审看；已有多个镜头时可以点击
   “合成整集预览”。

当前可用的 Wan2.2 TI2V 5B 引擎在远程 GPU 服务器生成真实人物动作视频。
“漫画动效”引擎使用应用内置 FFmpeg，对首帧执行缓慢推近、
平移、摇镜或稳定静帧，输出无音频、H.264、`yuv420p` 的标准 MP4。它用于
立即制作动态分镜和验证后续剪辑流程，不等同于生成新人物动作的 AI I2V。

镜头视频、Manifest 和整集无声预览保存在：

```text
projects/<项目名>/production/videos/episode_<集号>/
```

每次生成都会登记 SQLite 任务和 Artifact，保留首帧、运镜、时长、分辨率、
帧率、生成时间、任务 ID 和编码器版本。

### 声音角色库与自动选角

完成小说处理后，先进入左侧“声音角色库”。这个页面分为两个页签。

“声音库”页签用于维护所有项目共用的音色：

1. 点击“导入克隆音色”，选择 3–15 秒、无音乐和混响的清晰单人录音。
2. 填写与录音逐字一致的参考台词，以及性别、年龄感、表演气质、音高、语速、
   标签和默认表演指令。
3. 选择“本人声音”“已获明确授权”或“原创合成音色”，填写来源说明并确认授权。
4. 导入后选择该声音，输入任意台词并点击“试听所选音色”。克隆音色会通过 SSH
   调用 3090 上的 CosyVoice 3；内置音色使用 Edge TTS。

“人物自动选声”页签用于当前项目的配音选角：

1. 点击“分析人物并自动匹配”。应用读取所有 Episode 的人物资料、出场描述和
   对白说话人，推断性别、年龄感、性格、主配角定位、音高和语速，再对声音库
   进行打分推荐。
2. 在“当前声音”下拉框中可以逐个人物改配，然后点击“保存手动分配”。手动选择
   会锁定，后续再次自动匹配也不会覆盖。
3. 审核完成后点击“应用到全部分镜”，声音参数才会写入 Episode JSON。更换声音
   会使原有口型与新语音不一致，因此应用会恢复干净 Wan 源视频、保留旧口型文件
   路径，并将相关镜头标记为“待重做口型”。
4. 回到“视频生成 → 配音与字幕”，按需试听、调整单镜头表演指令，然后重新生成
   配音、对白镜头口型和最终成片。

共享声音库和参考音频保存在：

```text
projects/_voice_library/library.json
projects/_voice_library/references/
```

每个项目的声音分配表保存在：

```text
projects/<项目名>/production/voice_assignments.json
projects/<项目名>/production/voice_library/
```

只应导入本人、已获明确授权或原创合成的声音。不要从公开视频截取他人声音进行
冒充或未经授权的发布；应用会保存来源、授权类型和备注，但使用者仍需保留合同
或其他授权凭证。

### 配音与字幕

镜头视频生成后：

1. 选择一个镜头，打开“配音与字幕”标签。
2. 选择“自动旁白”“角色对白/自定义文案”或“本镜头静音”。
3. 选择 Edge TTS 或“CosyVoice 3 · 3090 本地音色克隆”，设置说话人、语速和
   配音文案；自动旁白模式下文案留空会使用镜头画面描述。
4. 使用 CosyVoice 时可选择 3–15 秒干净单人参考音频，并填写与音频逐字一致的
   “参考台词”；“表演指令”可填写年龄感、情绪、力度和语气。
5. 点击“试听当前文案”审核当前音色。未指定参考音频时，应用会先用当前 Edge
   音色创建基础参考；同名说话人的镜头会复用同一绑定。
6. 选择是否烧录中文字幕，点击“保存视频参数”。
7. 在生成视频前点击“按配音规划时长”。应用会离线估算对白时长、确保整集目标
   不少于 60 秒，并在表格中显示“需重生成”或“建议拆 N 段”。
8. 对白镜头可勾选“启用人物口型”，设置目标人物以及单人自动选择或按说话人
   跟踪。先到“连接与设置”检测 LatentSync 1.6；未安装时点击“安装/修复
   LatentSync 1.6”。
9. 单镜头可点击“生成当前镜头口型”。多人镜头选择“按说话人自动跟踪”时，目标
   人物必须已经锁定定妆照；应用会用 InsightFace 身份向量逐帧锁定该人物，匹配
   低于安全阈值会失败，不会让最大脸误开口。结果清单记录定妆照、阈值和实际
   身份匹配分数。
10. 点击“批量生成整集口型”可自动检查整集：旁白和已完成镜头直接跳过；缺少
    选中视频、定妆照、对白或目标人物不在画面的镜头会列出原因；可执行镜头按
    顺序处理，每镜完成即写回，失败后再次点击即可续跑。批次只在结束时恢复一次
    ComfyUI，避免每个镜头反复重启。
11. 点击“生成配音成片”。应用会生成逐镜头 WAV/MP3 和 SRT；历史视频短于配音时
   会平滑调整整段动作，不再直接冻结最后一帧，并把真实时长写回下一次视频任务。
12. 点击“播放带声成片”审看结果。

逐镜头配音文件保存在：

```text
projects/<项目名>/outputs/episodes/<项目拼音_集号>/yinpin/
```

带声成片和整集字幕分别保存在：

```text
projects/<项目名>/outputs/episodes/<项目拼音_集号>/shipin/
projects/<项目名>/outputs/episodes/<项目拼音_集号>/zimu/
```

当前默认配音引擎为 Edge TTS，需要联网但不需要 API Key。CosyVoice 使用 GPU
服务器上的 `Fun-CosyVoice3-0.5B-2512`，服务状态可在“连接与设置”中检测和启动。
新服务器可直接点击“安装/修复”，应用会上传随包部署脚本、安装独立环境、通过
HF 镜像下载精简推理模型并启动服务。
默认勾选“失败时回退 Edge”，因此临时断线不会让整集任务完全丢失；每个镜头的
Manifest 会记录请求引擎、实际引擎和回退原因。

服务器模型与运行目录：

```text
/root/cosyvoice-models/Fun-CosyVoice3-0.5B
/root/cosyvoice-runtime/CosyVoice
/root/cosyvoice-env
/root/cosyvoice-service
```

迁移到其他 GPU 服务器时，将项目中的 `scripts/gpu/cosyvoice/` 上传后执行
`install.sh`。脚本使用 `HF_ENDPOINT=https://hf-mirror.com`，下载完成后运行
`start.sh`；服务仅监听服务器本机端口，由桌面应用通过 SSH 调用。

LatentSync 1.6 的可复用部署文件位于 `scripts/gpu/latentsync/`。也可直接在应用
中点击安装；服务器持久盘目录为 `/root/autodl-tmp/LatentSync`、
`/root/autodl-tmp/latentsync-env` 和 `/root/autodl-tmp/huggingface`。3090 推理前
应用会停止 ComfyUI 和 CosyVoice，避免 18GB 口型模型与其他服务争抢显存，并在
原本在线时于任务结束后恢复 ComfyUI。部署目录还包含 `face_detector.py`，用于
把官方“选择最大脸”替换为可选的定妆照身份跟踪。

### 锁定定妆照与人物身份参考

选择并锁定角色定妆照后，单人分镜任务会把该选择传入远程工作流。设置页的
“安装人脸身份参考”会通过 `HF_ENDPOINT=https://hf-mirror.com` 下载 SDXL
IP-Adapter Plus Face 和 CLIP Vision，并校验文件哈希。状态栏会区分“模型文件
存在”和“人脸身份参考可调用”。

普通图生图会同时复制参考照的近景构图，不适合作为分镜身份锁，因此当前不再
用它套角色定妆照。实测柔美男性参考通过 IP-Adapter Plus Face 仍可能发生性别
漂移，所以男性镜头自动使用强化的男性、年龄、发型和服装文本锁；女性单人
镜头可使用 SDXL 人脸身份参考。生成结果仍需在首帧质检中确认性别、身份、动作
和场景，不能仅凭“适配器已调用”自动通过。

## 8. 项目总览跳转

## 10. 安全说明

- SSH 密码不会通过 `QSettings` 保存到磁盘。
- 应用只保存服务器地址、端口和用户名。
- 长时间生成任务关闭窗口后可能继续在服务器端执行。
- 删除模型、数据库或已审核产物等破坏性操作不在当前 GUI 中提供。
