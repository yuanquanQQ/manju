# AI 漫剧生成系统：项目启动说明

> 适用目录：`C:\Users\11325\Desktop\novel2anime_source_no_dependencies_20260813`  
> 当前架构：Windows 本地桌面应用负责操作和保存项目；RTX 3090 是远程 GPU
> 服务器，负责图片、MiniMax H3 视频和 CosyVoice 配音生成。

## 1. 每天最简单的启动方法

### 第一步：启动 3090 服务器

先在 GPU 服务商控制台启动 RTX 3090 实例，等待 SSH 状态可连接。

本地电脑不需要 3090，也不要在本机安装 CUDA。项目通过 SSH 调用远程服务器。

### 第二步：启动桌面应用

双击：

```text
C:\Users\11325\Desktop\novel2anime_source_no_dependencies_20260813\start_gui.bat
```

也可以在 PowerShell 中运行：

```powershell
cd C:\Users\11325\Desktop\novel2anime_source_no_dependencies_20260813
.\.venv\Scripts\python.exe main.py gui
```

桌面窗口出现后，程序本体就已启动。命令行窗口不要关闭；它会显示运行错误和
后台任务日志。

### 第三步：选择项目

在左上角项目选择框中选择已有项目，例如 `jueshi`。每个项目独立保存小说、
角色、分镜、图片、视频和音频，切换项目不会覆盖其他项目。

如果要制作另一部小说，点击“新建项目”，使用新的英文或拼音项目名。

### 第四步：连接 GPU 服务器

进入左侧“连接与设置”：

1. 确认服务器地址、SSH 端口和用户名。
2. 输入本次服务器的 SSH 密码。密码只保存在当前应用内存，不会写入磁盘。
3. 点击“检测连接”。
4. 状态显示 GPU 型号、显存和 ComfyUI 情况后，连接成功。

服务器每次重启后，SSH 密码可能变化，应以 GPU 服务商控制台显示的信息为准。

### 第五步：按当前任务启动模型服务

- 处理小说、重新分析人物和分镜：点击“检测文本模型”；未就绪时点击
  “启动本地模型”。
- 生成角色定妆、分镜首帧或 H3 视频：点击“启动 ComfyUI”。
- 使用本地角色音色配音：点击“检测 CosyVoice”；未运行时点击
  “启动 CosyVoice”。
- 首次部署 CosyVoice，或服务器环境被重装：点击“安装/修复”。程序通过
  `HF_ENDPOINT=https://hf-mirror.com` 下载推理所需模型。

CosyVoice 与视频引擎（H3/ComfyUI）会争用 3090 显存。应用在开始生图或 H3 视频前会
自动停止 CosyVoice；需要配音时再启动即可。也可以手动点击“停止并释放显存”。

## 2. 推荐的完整制作顺序

### 2.1 小说处理

进入“小说处理”：

1. 导入 TXT、Markdown 或已有章节数据。
2. 点击处理按钮，等待章节切分、人物抽取和分镜生成完成。
3. 在页面中检查切分出来的人物、章节和分镜数量。
4. 如果结果不满意，使用“重新处理”，旧结果会先备份到
   `production/backups/`，再重新分析。

本地文本模型默认文件：

```text
C:\Users\11325\Desktop\novel2anime_source_no_dependencies_20260813\models\llm\Qwen.Qwen3.5-9B.Q4_K_M.gguf
```

默认接口为 `http://localhost:1234/v1`。这是本机文本分析服务，不是 3090 上的
ComfyUI。

### 2.2 角色定妆

进入“角色定妆”：

1. 选择真人、游戏 CG、中国水墨等视觉风格。
2. 修改角色正向提示词、负面提示词和定妆预设。
3. 选择一个或多个生图模型，生成候选图片。
4. 对满意的候选点击“设为定妆”。
5. 需要重做时点击“解除定妆”，再生成并选择新图片。

每张候选图都会保存生成模型和精确到秒的生成时间。

### 2.3 分镜脚本与首帧

进入“分镜脚本”：

1. 检查每个镜头的画面描述、角色动作、环境动作、运镜、时长和转场。
2. 可直接修改镜头提示词、负面提示词和统一风格。
3. 点击保存。
4. 对缺图镜头点击“自动补全缺失画面”。
5. 已有首帧过于僵硬或镜头彼此割裂时，点击“重做连续首帧”。应用会保留
   旧候选图，重新规划连续组后按镜头顺序生成并选中新版本。

小说处理时如果勾选自动生成首帧，系统会在分镜生成后直接调用 ComfyUI，并把
生成图片回填到对应镜头。

连续首帧采用保守引用：只有同一场景且出场人物集合完全相同，下一镜头才会把
上一镜头作为图生图参考；人物阵容改变、闪回或换场会自动断开引用，只继承
场景轴线、光向和道具等文字锚点。这样既能保持服装和环境连续，又不会把上一
镜头不该出现的人物带进新画面。首帧会优先选择动作发生前一刻，而不是正面
站立展示。

### 2.4 MiniMax H3 视频

进入“视频生成”的视频标签：

1. 选择分集和镜头。
2. 确认首帧图片已经自动填入；需要明确动作终点时可准备尾帧，H3 支持首尾帧输入。
3. 默认使用 MiniMax H3 FL2VA（`minimax_h3_fl2va`）；“漫画动效”只适合静态推拉预览。
4. 检查系统自动填入的人物动作、环境动作、负面提示词、运镜和时长。
5. 点击生成选中镜头，等待进度条完成。
6. 镜头生成后，可合成整集预览。

H3 视频自带原生音效/对白：音频模式 `off` 为静音，`ambience_sfx_music`（默认）为
环境音+音效+音乐，`native_full` 为原生对白。H3 默认使用 **T8 音视频增强图**
（`comfyui-minimax-h3-audio-T8` 自定义节点，联合 conditioning + 双钟采样器），
首次使用前请在“连接与设置”安装/修复 T8 音频包；如需回退官方节点图，可在工作流
脚本用 `--engine official`。为减少动作诡异和面部缺失，首帧应保证
脸部清晰、四肢完整，动作提示词一次只描述一个主要动作，避免大幅旋转、快速奔跑和
复杂多人肢体接触。

**整集脚本链路(镜头连贯)**:`scripts/generate_episode_h3.py` 逐镜头生成时默认开启
末帧→首帧链接——本地用 ffmpeg 从镜头 N-1 的已生成视频抽取末帧 PNG,作为镜头 N 的首帧,
使相邻镜头在像素级精确交接,提示词首段自动从"从首帧开始"切换为"无缝承接上一镜末帧"。
同时抽上一镜末尾约 2 秒音频作为镜头 N 的 `reference_audio`(T8 `drive_audio`),让模型
承接上一镜的音色与语流,prompt 追加 "Voice continuity" 指令锁定同一说话人。
开关 `--chain-shots`(默认开,`--no-chain-shots` 退回独立首帧);抽帧/抽音频失败自动
回退故事板关键帧,不阻塞生成。续跑时已通过校验的镜头(SKIP)同样提供末帧与末尾音频
给下一镜。

### 2.5 配音、字幕与最终视频

进入“视频生成”的“配音与字幕”标签：

1. 为镜头选择自动旁白、角色对白、自定义文案或静音。
2. 选择 `CosyVoice 3·3090 本地音色克隆` 或 Edge 中文音色。
3. 使用 CosyVoice 时，最好选择 3–15 秒的清晰单人参考音频，并填写与音频
   完全一致的参考台词。
4. 可填写“情绪/表演指令”，先点击“试听当前文案”检查声音。
5. 同名说话人会在批量生成时复用同一音色。
6. 点击生成带声成片。

最终流程会生成逐镜头音频、SRT 字幕、整集字幕和带 AAC 音轨的 MP4。台词长于
镜头时会冻结末帧补足，不会截断语音。

## 3. 第一次在新电脑上安装

如果当前电脑的 `.venv` 已存在并能正常启动，可以跳过本节。

### 3.1 环境要求

- Windows 10/11
- Python 3.11 或 3.12，推荐 3.11
- 至少 15 GB 本地可用空间
- FFmpeg；项目也可以通过 `imageio-ffmpeg` 使用随包二进制
- 可连接互联网和远程 RTX 3090 服务器

### 3.2 创建环境并安装

打开 PowerShell：

```powershell
cd C:\Users\11325\Desktop\novel2anime_source_no_dependencies_20260813
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

如果项目被复制到其他盘符或目录，需要把 `.env` 中的 `LLM_MODEL_PATH` 改为新
电脑上的 GGUF 实际位置。

### 3.3 运行环境诊断

```powershell
.\.venv\Scripts\python.exe main.py doctor --skip-llm
.\.venv\Scripts\python.exe main.py info
```

诊断通过后双击 `start_gui.bat`。

## 6. 常见故障

### `localhost:1234` 连接失败

这是本地 Qwen 文本模型没有启动，不是 GPU 服务器故障。

1. 进入“连接与设置”。
2. 点击“启动本地模型”。
3. 等待状态变为已就绪，再重新处理小说。
4. 如果仍失败，确认 `.env` 中的 `LLM_MODEL_PATH` 指向存在的 GGUF 文件。

### SSH 或 GPU 检测失败

- 确认 3090 实例已经完全启动。
- 从服务商控制台核对最新地址、端口、用户名和密码。
- 密码关闭应用后不会保留，需要重新输入。
- 先点击“检测连接”，不要直接开始生成。

### GPU 在线，但 ComfyUI 未启动

在“连接与设置”点击“启动 ComfyUI”，等状态变为在线，再生成图片或 H3 视频。

### CosyVoice 未安装或无法启动

1. 点击“检测 CosyVoice”。
2. 显示未安装时点击“安装/修复”。
3. 首次安装需下载约 5 GiB 推理文件，等待进度完成。
4. 安装完成后点击“启动 CosyVoice”。
5. 如果只想先输出成片，可勾选失败时回退 Edge TTS。

### 显存不足

CosyVoice、图片模型和 H3 视频引擎不应同时占用 3090。

- 配音完成后点击“停止并释放显存”。
- 再启动 ComfyUI 进行生图或视频。
- 应用在正式生图/H3 视频任务前也会自动执行这一步。

### 生成的视频没有对白或声音

单镜头 H3 视频自带原生音效/对白（音频模式 `native_full`）。如果仍缺少对白，
请在“配音与字幕”标签确认文案、说话人和音频模式，并生成“带声成片”，最终打开
`episode_XXX_dubbed_*.mp4`。

### 关闭应用后后台任务怎么办

关闭窗口不会撤回已经提交给 GPU 的 ComfyUI 任务，但本地下载、合成和状态更新
会中断。生成期间建议保持桌面应用和命令行窗口开启。
