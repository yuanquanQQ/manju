# 个人项目高质量生产工作流

本项目不复制 CineGraph 的 Spring AI Graph、云 VOD、模型工厂或分布式任务架构。
只保留对成片质量直接有用的阶段划分、审核门禁、镜头资产绑定和断点恢复。

## 技术边界

- 单机桌面应用：Python + PySide6。
- 单项目数据库：`projects/<project>/database/world.db`（SQLite）。
- 大型图片、视频、音频直接存项目目录，SQLite 仅保存任务、产物索引和审核记录。
- GPU 服务器只运行 ComfyUI 和当前生成任务，不部署独立数据库、Redis、消息队列或 Web 服务。
- 每个生成目录包含 manifest，可在 SQLite 不可用时人工追溯模型、提示词、种子和输入文件。

## 六个生产阶段

1. 剧本与分镜：一章一集，3–5 分钟；第一集为 45 镜头、约 292.66 秒。
2. 角色选角：Z-Image Turbo INT8 每角色至少生成 4 张单人母版，人工只看脸、气质和服装。
3. 角色设定板：选中的母版交给 Qwen-Image-Edit 2511 INT8，分别生成正面、严格 90°侧面和背面；逐角度审核后拼板，并保留独立正面身份锚点。
4. 镜头关键帧：首帧先由 Z-Image 生成构图底图，再由 Qwen Edit 使用最多两位已批准演员锚点锁脸锁服装；尾帧只编辑已批准首帧的单一动作状态，不重新造景。每帧至少 2 个候选。
5. 镜头视频：量化 MiniMax H3 使用首尾帧、单动作时间线、镜头把手和转场结束规则；每镜头至少 2 个候选，并检查视频流、音轨、分辨率、帧率、时长以及五点帧接触表。
6. 声音与合成：对白使用独立角色音色和表演参数；环境声、效果声、配乐与对白分层；只允许已批准视频进入整集转场和响度合成。

## 审核门禁

- 技术检查通过不等于审美通过。
- 角色母版未选中时，不允许生成三视图。
- 三视图和身份锚点未批准时，不允许生成人物关键帧。
- 首帧未批准时，不允许生成尾帧；首尾帧未批准时，不允许生成 H3 视频。
- H3 候选默认不自动选中；必须人工检查身份、动作、口型/声音和镜头衔接。
- 任一上游资产被替换时，只将相关下游结果标记过期，不删除历史文件。

## 当前模型

- 中国真人角色母版：`z_image_turbo_int8_convrot.safetensors`
- 身份一致编辑和多角度：`qwen_image_edit_2511_int8_convrot.safetensors`
- 多角度 LoRA：`qwen-image-edit-2511-multiple-angles-lora.safetensors`
- 视频：`minimax_h3_fl2va_pruned_int8_convrot.safetensors`
- 不使用 Wan，不使用上述模型的原始全精度权重。
