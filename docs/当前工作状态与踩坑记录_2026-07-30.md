## 5. 已经踩过的坑

### 坑 1：不能只写“俊美少年”

`pretty-boy`、大眼、软脸颊、小下巴等词叠加后，Flux 很容易把男主生成成女性。

正确做法：

- 年轻与男性骨相必须同时存在
- 明确写 `unmistakably male young man`
- 明确男性颈部、平直男性胸部、男性下颌结构
- 同时保留无胡须、年轻、清秀，避免生成大叔

### 坑 2：中文身份锁与英文正文没有自动绑定

分镜正文使用 `Qin Feng`，身份锁只写“秦风”时，模型在单人镜头可能猜对，在多人镜头却可能把男性约束给了另一个人。

最新修复：

- 身份锁同时写 `Qin Feng (秦风)`
- 增加当前画面的明确性别映射
- 明确说明英文名与中文名是同一个人

这项修复已经写入代码，但**还没有在 GPU 上复测**。

### 坑 3：通用露脸规则不能覆盖物证特写

以前所有镜头都会追加“人物中近景、完整露脸”的视频安全规则。

结果：

- `macro insert`
- `POV`
- `top-down`
- `detail shot`

也会被强行生成整个人。

最新修复：

- 物证特写跳过人物身份脸部提示
- 明确要求零张脸、零个完整人物
- 只允许手、袖口、植物、契约或物证进入画面
- 物体必须占据画面主体

这项修复已经写入代码，但**还没有在 GPU 上复测**。

### 坑 4：同人物不等于可以无条件沿用上一张图

从全景直接切到微距、POV 或俯拍时，即使演员相同，也不能把上一张整人构图作为强参考。

最新修复：

- 微距、插入、POV、俯拍镜头强制断开参考
- 物证镜头之后的下一镜也不继承物证构图
- 普通同演员参考强度从过强的 0.70 调整到约 0.82～0.88

### 坑 5：不能生成首帧后直接跑 Wan

首帧一旦错性别、错脸、错构图，Wan 只会把错误动画化，并可能进一步出现：

- 面部缺失
- 动作诡异
- 身体融化
- 帧间身份变化

正确顺序必须是：

1. 生成关键帧。
2. 做联系图。
3. 检查人物、服装、动作、轴线和构图。
4. 只重做失败镜头。
5. 关键帧全量通过后再生成 Wan。

### 坑 6：旧镜号素材会污染新版分镜

旧版只有 8 镜，新版有 25 镜。如果按 `shot_001.png` 等文件名自动回退，会把旧剧情画面绑定到新剧情。

已通过 `explicit_only` 解决。不要改回旧的自动回退策略。

### 坑 7：后台进程列表可能短暂显示不完整

Windows 第一次查询没有显示 Python 进程，但远端任务实际正在运行。

确认任务是否运行时需要同时检查：

- 本地日志是否增长
- 本地 Python 命令行
- 远端 `generate_shots.py`
- ComfyUI `/queue`

不能只看一次 `Get-Process python` 就判断任务失败。
