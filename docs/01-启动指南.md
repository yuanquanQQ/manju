## 4. 配置 LLM 服务

本项目走 **OpenAI 兼容协议**（POST `{base}/v1/chat/completions`）。服务可运行在开发机，也可运行在 RTX 3090 GPU 服务器并通过局域网访问。支持：
- **LM Studio**（推荐，本项目默认）
- **Ollama**（开启 OpenAI 兼容模式即可）
- **vLLM / text-generation-webui**（OpenAI 扩展）

### 4.1 在 GPU 服务器启动 LM Studio

1. 打开 LM Studio → 搜索并加载 `qwen/qwen3.5-9b`（GGUF Q4_K_M）
2. 左侧 Developer 面板：
   - **Start Server** → 勾选 **Enable OpenAI Compatible Server**
   - 端口保持默认 `1234`
3. 顶部状态变绿后即就绪

### 4.2 验证模型已加载

浏览器或 curl：

```powershell
curl http://localhost:1234/v1/models
```

应能看到 `"id": "qwen/qwen3.5-9b"`。

### 4.3 修改 `.env`

如果端口或模型不同，编辑 [.env](file:///e:/work/cc/pingtai/video/.env)：

```ini
LLM_BASE_URL=http://GPU服务器地址:1234
LLM_MODEL=qwen/qwen3.5-9b
LLM_TIMEOUT=600
LLM_MAX_RETRIES=3
EXTRACT_MAX_CHARS=6000
EXTRACT_CONCURRENCY=1
```

> 配置加载优先级：**环境变量 > .env > 代码默认值**
> 旧变量名 `OLLAMA_URL` / `OLLAMA_MODEL` 仍兼容，但建议改用新名 `LLM_BASE_URL` / `LLM_MODEL`。

## 9. 全量抽取

```powershell
python main.py ingest jueshi
```

- 单章 ~3-8 秒
- 1000 章 ≈ 1-2 小时

## 11. 常见问题

### Q1: Ollama 连接失败

```
requests.exceptions.ConnectionError: ... 11434 ...
```

检查：
- `ollama serve` 是否在跑
- `.env` 里 `OLLAMA_URL` 是否正确
- 端口是否被防火墙拦了

### Q2: JSON 解析失败

```
ch100 抽取彻底失败: Expecting value: line 1 column 1
```

通常因为模型没有严格遵循 system prompt。处理：
1. 重跑：`python main.py ingest jueshi`（已抽取会跳过，只重试失败的）
2. 或者在 `.env` 里换更稳定的模型
3. 看 `logs/app.log` 找到具体失败章节，手动检查

### Q3: 想换模型 / 改超时

改 `.env`：

```ini
OLLAMA_MODEL=qwen2.5-14b
OLLAMA_TIMEOUT=900
```

然后重新 `python main.py ingest jueshi`。

### Q4: 想清空重来

```powershell
# 删除整个项目重做
Remove-Item -Recurse -Force projects\jueshi
python main.py create jueshi
# 重新拷章节
Copy-Item -Recurse ...\chapters\* projects\jueshi\chapters\
python main.py ingest jueshi
```

### Q5: 想只跑某一段章节

临时把不需要的章节挪走：

```powershell
# 比如只跑 100-200 章
Get-ChildItem projects\jueshi\chapters\chapter_*.json |
  Where-Object { $_.Name -notmatch 'chapter_0(0[0-9][0-9]|1[0-9][0-9])\.json' } |
  Move-Item -Destination projects\jueshi\chapters_backup\
```

跑完再移回来。
