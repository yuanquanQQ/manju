# 阶段 09：声音与自动剪辑

## 1. 阶段目标

把镜头视频、对白和声音设计组装成完整剧集，输出可继续编辑的时间线、代理文件和最终 MP4。本阶段负责补齐产品目标中的配音、字幕、音效、配乐、片头和片尾。

FFmpeg 作为可靠的媒体探测、转码和最终合成核心；MoviePy 可用于编排辅助，但不作为唯一渲染依赖。

### 当前实施状态（2026-07-27）

- 已实现逐镜头 `transition_out`、转场帧数、画面运动方向和头尾余量的持久化。
- 已实现直接切换、动作匹配切换、交叉溶解和淡入黑场的界面选择。
- 整集无声预览合成器会读取逐镜头时间线；交叉溶解和淡入黑场通过 FFmpeg
  `xfade` 实际渲染，直接切换和动作匹配保持无特效硬切。
- 已记录整集 Manifest 中的镜头顺序和转场参数。
- 对白、环境音、音效、音乐、字幕以及 J-cut/L-cut 仍属于后续工作。

## 2. 输入与输出

### 输入

- 审核通过的 Episode/Scene/Shot 脚本。
- 标准化镜头视频。
- 对白、旁白、角色和情绪/语速标注。
- 项目声音资产、音乐和授权信息。
- 输出 Profile：分辨率、帧率、编码、响度和字幕格式。

### 输出

```text
production/episodes/{episode_id}/
├─ timeline.json
├─ audio/
│  ├─ dialogue/
│  ├─ narration/
│  ├─ sfx/
│  ├─ ambience/
│  └─ music/
├─ subtitles/
│  ├─ episode.srt
│  └─ episode.ass
├─ proxies/
├─ masters/
│  ├─ episode_video.mp4
│  ├─ episode_audio.wav
│  └─ episode_final.mp4
└─ manifest.json
```

## 3. 配音系统

### 角色选角

- 每个角色绑定稳定 `voice_profile_id`。
- Voice Profile 保存引擎、音色、语言、语速、音高、情绪能力和许可备注。
- 主要角色先生成固定台词集，由人工选定后锁定。
- 同一角色换 TTS 模型或音色时创建新版本。

### 台词生成

1. 从审核过的导演数据读取台词，不直接重新理解小说。
2. 规范化标点、读音、专名和数字。
3. 为 TTS 创建可控情绪、速度和停顿参数。
4. 分句生成并保存原始音频。
5. 检查静音、爆音、截断、时长异常和采样率。
6. 人工修正专名读音和关键表演。

需要保留角色发音词典，避免同一专名在不同镜头读法不一致。

## 4. 字幕与对齐

- 字幕文本来自最终配音台词版本。
- 优先使用 TTS 返回的时间戳；否则用本地强制对齐或语音识别对齐。
- 字幕按语义和可读速度断句，不按固定字数粗暴切分。
- 支持 SRT 交付和 ASS 样式字幕。
- 安全区、字号、行数和颜色在输出 Profile 中配置。
- 烧录字幕与外挂字幕都从同一时间线生成。

## 5. 声音设计

每个场景至少有：

- 环境底声。
- 必要动作音效。
- 对白/旁白。
- 可选配乐。

原则：

- 音乐不能遮蔽对白。
- 音效与画面动作时间对齐。
- 转场声音服务叙事，不为每个切镜机械添加。
- 音乐、字体和音效记录来源与许可；无许可素材不得进入可发布母版。

V1 可先使用人工维护的本地素材库和规则匹配，再逐步增加生成式音乐/音效适配器。

## 6. 时间线模型

`timeline.json` 是本阶段的核心可编辑产物，至少包含：

- 视频轨、对白轨、旁白轨、环境音、音效、音乐和字幕轨。
- 每个 Clip 的源 Artifact、入点、出点、时间线位置、音量和淡入淡出。
- 转场及参数。
- 片头、片尾和章节标识。
- 时间基、帧率和总时长。

时间线引用稳定 Artifact ID。替换镜头视频或配音时，重新解析受影响轨道，不重建全部导演数据。

## 7. 合成流程

1. 媒体预检：编码、帧率、采样率和时长。
2. 生成代理时间线进行快速预览。
3. 对齐视频、对白和字幕，处理时长冲突。
4. 混合环境音、音效和音乐。
5. 进行响度、峰值和静音检查。
6. 渲染视频母版与音频母版。
7. 合成字幕、片头、片尾和发布编码。
8. 使用 `ffprobe` 验证最终文件并生成 Manifest。

## 8. 自动质量检查

- 所有镜头和音频引用存在。
- 时间线无负时长、非法重叠和空洞。
- 字幕不越界、不超安全区、时码递增。
- 配音无意外静音、削波和过低音量。
- 最终视频可从头到尾解码，音视频时长差在容差内。
- 抽样检查字幕与语音对齐。
- 响度目标由发布 Profile 配置并记录，不在代码中散落常量。

10. 输出可供其他剪辑软件转换的通用清单；V1 不强制实现完整 NLE 工程格式。

## 10. 交付物

- 角色 Voice Profile 与本地 TTS 适配。
- 可复用发音词典。
- 字幕生成与对齐。
- 多轨时间线、声音设计和 FFmpeg 合成。
- 代理、母版、最终 MP4 与完整 Manifest。

## 11. Definition of Done

- [ ] 主要人物声音可辨识且同集一致。
- [ ] 所有对白有音频和匹配字幕，无漏句和重复句。
- [ ] 字幕与配音抽样对齐误差在约定范围内。
- [ ] 自动生成的时间线可局部替换镜头或台词后重渲染。
- [ ] 最终视频带配音、字幕、环境音、必要音效、音乐和片尾。
- [ ] 最终文件通过 ffprobe、解码、时长、响度和字幕安全区检查。
- [ ] 音乐、字体和音效均有来源/许可记录。
- [ ] 3–5 分钟样片可一次命令从已审核素材合成。

## 12. 风险与退出条件

- 如果配音时长长期与镜头不匹配，应回到导演阶段拆镜/改词，不能靠大幅变速解决。
- 如果本地 TTS 情绪不足，V1 可允许关键台词人工替换，但时间线和字幕契约不变。
- 音乐版权是发布风险，默认只用明确可用的本地素材或用户提供素材。
