# 阶段 10：桌面 GUI

## 1. 阶段目标

使用 PySide6 提供完整桌面工作流，让用户无需手工编辑数据库或运行多条 CLI，即可创建项目、导入小说、审核结构化数据、管理资产和分镜、控制生成任务、恢复失败以及导出剧集。

GUI 是现有应用服务的客户端，不重新实现 Pipeline 逻辑。

## 2. 用户工作流

```text
创建/打开项目
  → 导入小说并确认章节
  → 解析并审核人物/事件/场景
  → 发布世界快照
  → 生成并审核视觉资产
  → 生成并编辑分集/分镜
  → 编译 Prompt
  → 生成/筛选图片
  → 生成/审核视频
  → 配音/字幕/时间线
  → 预览并导出
```

每一步显示前置条件、当前版本、待审核项和失败项，不让用户猜测下一步。

## 3. 架构

推荐分层：

```text
Qt Widgets / Views
      │ signal/slot
ViewModel / Presentation Model
      │ async commands + events
Application Services
      │
Pipeline / Repositories / Adapters
```

约束：

- View 不直接执行 SQL、不直接请求 ComfyUI、不调用 FFmpeg。
- GPU、LLM 和媒体任务必须运行在后台工作线程或独立进程。
- UI 更新只在主线程进行。
- 所有长任务支持取消；取消是协作式状态，不强杀数据库事务。
- CLI 与 GUI 调用同一应用服务和数据契约。

## 4. 页面与功能

### 4.1 项目中心

- 创建、打开、归档和最近项目。
- 显示项目路径、版本、磁盘占用和健康状态。
- 备份、恢复和迁移提示。

### 4.2 小说导入与解析

- 选择 TXT/Markdown/JSON。
- 预览编码和章节切分，支持合并/拆分。
- 显示解析进度、速度、失败和预计剩余时间。
- 原文与人物、事件、对白、证据并排审核。
- 实体合并/拆分和人工锁定。

### 4.3 世界与资产

- 人物、地点、组织、道具和时间线浏览。
- 搜索并查看原文证据。
- 人物卡和视觉规格编辑。
- 候选资产网格、对比、评分、拒绝和发布。
- 显示资产版本及下游影响。

### 4.4 导演与分镜

- Episode/Scene/Shot 树。
- 镜头表格与分镜卡片两种视图。
- 编辑时长、人物、动作、景别、对白和资产引用。
- 显示事实冲突、连续性问题、资产缺口和成本估计。
- 局部重生成、锁定和版本对比。

### 4.5 生成工作台

- Prompt/RenderSpec 查看和项目级覆写。
- 图片候选、视频预览和相邻镜头对比。
- 队列优先级、暂停、恢复、取消和重试。
- 实时日志、GPU 状态、显存、耗时和磁盘占用。
- 按错误类型筛选失败项。

### 4.6 声音与导出

- 角色音色选择和试听。
- 台词、发音、字幕和时间码编辑。
- 简化时间线预览与音量控制。
- 导出 Profile、进度、最终验证和打开输出目录。

## 5. 状态与事件

GUI 通过应用事件更新：

- `JobProgressChanged`
- `JobStateChanged`
- `ArtifactCreated`
- `ReviewRequired`
- `EntityUpdated`
- `UpstreamInvalidated`
- `HealthStatusChanged`

进入页面时先读取持久化状态，再订阅增量事件。应用重启后不能依赖内存事件恢复 UI。

## 6. 可用性要求

- 破坏性操作显示精确影响范围，并优先采用可恢复方式。
- 重新生成前提示哪些下游结果会变为过期。
- 每个失败项提供“原因、建议动作、查看日志、重试”。
- 表格、树和网格支持大数据量虚拟化/分页，不能一次加载 1000 章全部正文和缩略图。
- 自动保存人工编辑，并有未保存/冲突提示。
- 关键操作提供撤销或版本回退。
- 界面文案以中文为主，技术参数有解释与安全默认值。

## 7. 性能与线程

- 数据库查询分页，缩略图异步加载并缓存。
- 视频用代理文件预览，不直接加载母版。
- 任务进度节流更新，避免大量信号阻塞主线程。
- 长时间模型服务建议独立进程，GUI 崩溃不终止已提交 GPU 任务。
- 关闭程序时询问：保持后台任务、暂停任务或取消任务。

## 8. 设置与诊断

设置页按能力分组：

- 路径和存储。
- LLM 与 Embedding。
- ComfyUI 和工作流。
- I2V、TTS、FFmpeg。
- 默认输出和质量 Profile。

“环境诊断”一键检查服务端点、模型、节点、FFmpeg、GPU、磁盘和数据库；显示可复制的诊断报告，但自动隐藏密钥和敏感环境变量。

## 9. 实施顺序

GUI 不宜等第九阶段才从零开始，可按以下增量交付：

1. 应用壳、项目中心、导航、统一错误弹窗。
2. 任务中心、后台执行、日志和环境诊断。
3. 小说导入、解析进度和世界数据浏览。
4. 实体审核、资产候选和版本管理。
5. 分集/分镜编辑与连续性问题面板。
6. 图片/视频生成工作台。
7. 配音、字幕、时间线预览和导出。
8. 完整端到端向导、可用性和性能优化。

## 10. 测试计划

### 自动测试

- ViewModel 和应用服务单元测试。
- 使用假的 LLM/ComfyUI/I2V/TTS Adapter 做 UI 集成测试。
- 项目打开、迁移、任务状态、编辑保存和失效传播。
- 大量章节、人物、候选缩略图的性能测试。

### 手工测试

- 新用户从空项目到 30–60 秒样片。
- 生成中关闭并重启应用。
- 服务掉线、OOM、磁盘不足和损坏输出。
- 修改已发布人物资产后查看影响提示和局部重算。
- Windows 缩放比例、中文路径、长路径和多显示器。

## 11. 交付物

- PySide6 桌面应用。
- 项目、小说、世界、资产、导演、生成、声音和导出页面。
- 任务中心、环境诊断和错误处理。
- 安装/启动说明及用户操作手册。
- UI 集成测试和完整验收记录。

## 12. Definition of Done

- [ ] 用户可在 GUI 内完成创建、导入、解析、审核、生成和导出。
- [ ] 所有耗时任务不阻塞界面，并可暂停、取消、恢复和重试。
- [ ] 应用重启后项目、任务、审核和进度状态正确恢复。
- [ ] 关键人工修改可追踪、锁定和回退。
- [ ] 上游修改能明确显示受影响的下游资产和镜头。
- [ ] 1000 章项目的列表浏览和搜索保持可用。
- [ ] 错误信息可操作，日志和诊断报告不泄露密钥。
- [ ] 新用户按文档可完成一集 3–5 分钟样片。

## 13. 风险与退出条件

- 如果服务层接口仍频繁变化，先完成任务中心和只读页面，避免在 GUI 中固化临时逻辑。
- 如果 GUI 只能控制“开始生成”而不能审核与恢复，它还不满足产品目标。
- 打包发布应在依赖和模型路径稳定后进行，V1 可先交付源码环境启动方式。
