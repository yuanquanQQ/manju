# 阶段 05：导演 Agent

## 1. 阶段目标

将小说事实和世界状态改编成可生产的分集、场景与镜头脚本。导演 Agent 既要保持剧情事实和人物动机，又要满足时长、镜头数量、资产可用性和 GPU 成本约束。

导演阶段输出的是“制作蓝图”，不是自然语言剧本散文。

## 2. 核心原则

- 分层规划：故事弧 → Episode → Scene → Shot，避免直接把每个事件机械变成镜头。
- 事实来自固定知识快照，新增设定必须显式标记为改编决定。
- 先规划信息、情绪和节奏，再决定景别和运动。
- 镜头脚本引用稳定人物/场景/道具和资产版本。
- 每个镜头可被单独生成、审核、重做和替换。
- 预算是输入：目标时长、镜头数、可用资产、分辨率和 GPU 时间。

## 3. 输入

- 目标章节范围和第三阶段知识快照。
- 第四阶段已发布的资产目录。
- 改编配置：每集时长、目标受众、旁白比例、对白密度、节奏和内容边界。
- 制作约束：镜头时长范围、最大角色数、可用场景、视频模型能力。

## 4. 输出层级

### EpisodePlan

- 标题、覆盖章节、主题、核心冲突、开场钩子和结尾悬念。
- 目标时长、场景列表、剧情保留/压缩/合并说明。
- 需要新增的资产和高风险镜头。

### ScenePlan

- 地点、时间、天气、进入/退出状态。
- 参与人物、场景目标、冲突、转折和情绪曲线。
- 预计时长、连续性约束和资产引用。

### ShotPlan

至少包含：

- `shot_id`、顺序、目标时长和叙事目的。
- 人物及其位置、动作、表情、服装和道具。
- 场景、时间、天气和关键视觉信息。
- 景别、机位、构图、镜头运动和焦点。
- 对白/旁白引用、环境音和音乐提示。
- 入帧状态、出帧状态以及与相邻镜头的连续性。
- 资产依赖、生成难度、备选方案和原文事实证据。

## 5. 规划流程

### 5.1 选材与分集

1. 读取章节事件、重要度、因果和人物弧。
2. 识别必须保留的转折、铺垫和回收。
3. 估算对白、动作和说明所需时长。
4. 在时长预算内合并重复信息，形成场景边界。
5. 保留改编日志，说明删减、合并和新增桥段。

### 5.2 场景规划

对每个场景明确“人物想要什么、阻碍是什么、结束时发生了什么变化”。只有空间变化而没有叙事变化的段落不应独立成场景。

### 5.3 分镜生成

- 优先使用可生产的镜头：1–2 个主要人物、动作清晰、运动可控。
- 复杂群像、长打斗、多人交互拆成短镜头。
- 对话场景建立空间后使用主镜头、正反打、反应和插入镜头。
- 每个镜头应有独立画面价值，避免所有对白都用静态正面中景。

### 5.4 连续性检查

规则检查至少覆盖：

- 人物是否在该时间点存活、在场并拥有对应能力/物品。
- 服装、伤势、手持物和站位是否连续。
- 场景时间、天气、光源和破坏状态是否连续。
- 对白说话人与原文事实是否冲突。
- 180 度轴线、视线方向和动作接续是否存在明显问题。
- 总时长是否等于镜头、转场和片头片尾预算。

### 5.5 生产可行性检查

根据资产和模型能力为镜头评分：

- 低风险：单人、轻动作、固定镜头。
- 中风险：双人互动、明显运镜、局部特效。
- 高风险：多人战斗、快速形变、复杂手部、长时间连续运动。

高风险镜头必须有拆镜或静态漫画式替代方案。

## 6. Agent 边界

建议拆为受控步骤，而不是一个超大 Prompt：

- `EpisodePlanner`：分集和剧情取舍。
- `ScenePlanner`：场景节奏和状态。
- `ShotPlanner`：镜头语言和制作规格。
- `ContinuityChecker`：事实与连续性检查。
- `BudgetChecker`：时长、资产和算力检查。

每一步输出严格 Schema，Pipeline 负责编排和重试，知识检索由知识服务提供。

## 7. 实施任务

1. 定义 Episode、Scene、Shot、AdaptationDecision 和 ContinuityIssue Schema。
2. 建立导演配置与镜头词典，限制合法景别、运镜和转场。
3. 实现章节选材、分集、场景规划和分镜的分步流程。
4. 实现知识检索上下文组装，禁止整本小说直接塞入 Prompt。
5. 实现时长估算、镜头复杂度和资产缺口报告。
6. 实现事实、状态和相邻镜头连续性规则检查。
7. 实现人工锁定：已审核场景或镜头不因局部重跑被覆盖。
8. 实现 JSON 与便于阅读的 Markdown 分镜表导出。
9. 建立 3 类基准：对话、动作、过场各至少一个场景。

## 8. 审核与评估

人工审核维度：

- 剧情事实与人物动机。
- 开场钩子、冲突、转折、悬念和节奏。
- 镜头多样性、可读性和视觉叙事。
- 对白长度、信息重复和旁白使用。
- 生产可行性与资产缺口。

自动指标：

- Schema 通过率。
- 无证据事实数量。
- 连续性错误数量。
- 目标时长偏差。
- 未发布资产引用数量。
- 高风险镜头比例与预计 GPU 成本。

## 9. 交付物

- 版本化导演 Schema 与配置。
- 分集、场景、分镜和检查 Agent。
- 资产缺口、连续性和制作预算报告。
- JSON/Markdown 分镜输出和人工修订机制。

## 10. Definition of Done

- [ ] 指定章节可生成完整 Episode → Scene → Shot 层级。
- [ ] 所有剧情事实带知识库证据或明确标记为改编决定。
- [ ] 所有角色、场景和道具引用稳定 ID。
- [ ] 总时长偏差在目标的 ±10% 内。
- [ ] 自动检查无阻断级事实、时间和资产错误。
- [ ] 高风险镜头有可执行的降级方案。
- [ ] 人工审核通过对话、动作、过场三类基准场景。
- [ ] 修改单个镜头不会重写已锁定的整集规划。

## 11. 风险与退出条件

- 如果镜头脚本仍大量引用不存在的资产，不进入 Prompt 批量生成。
- 如果分镜时长和配音时长无法闭合，先统一对白估时规则。
- 如果 Agent 频繁杜撰设定，应减少自由上下文，增强结构化检索和规则检查。
